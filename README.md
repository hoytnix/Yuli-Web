# @yuli-ai/web

Ultra-low-latency, edge-optimized cognitive persona runtime for browser PWAs, WebGL titles, and Telegram Mini Apps.

## Features
- **Zero Server Costs:** 100% client-side inference via WebGPU / WASM SIMD.
- **OPFS Caching:** Model weights cached permanently in the browser via Origin Private File System.
- **Isolated Worker:** Generation runs in a dedicated background worker to prevent game-thread UI lag.
- **Cognitive FSM:** Zero-latency parsing for `<thought>`, `<dna>`, and `<state_vector>` coordinates.
